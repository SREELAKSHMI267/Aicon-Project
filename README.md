# AICON – AI-Powered Conference Management System

Developed a web-based conference management system to streamline the organization and management of academic conferences. The platform supports conference workflows such as paper submission, participant management, conference information, and administrative activities, providing a centralized system for organizers, reviewers, and participants. Built using Next.js, TypeScript, Tailwind CSS, Firebase, Genkit, and Gemini 2.5 Flash, with AI-powered capabilities integrated to enhance conference management and user experience.
